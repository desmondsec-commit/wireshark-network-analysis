🔎 Wireshark Network Traffic Analysis

📌 Project Overview

This project documents my hands-on learning and practical analysis of network traffic using Wireshark.

The objective is to develop practical skills in packet analysis, network protocols, traffic investigation, and identifying potentially suspicious network activity.

---

🎯 Objectives

- Understand how network traffic is captured and analyzed.
- Identify common network protocols.
- Use Wireshark filters to investigate traffic.
- Examine packet-level information.
- Develop basic network-security investigation skills.
- Document findings clearly and professionally.

---

🛠️ Tools & Technologies

- Wireshark
- Linux / Windows
- TCP/IP
- Network protocols
- Packet analysis

---

🔬 Investigation Process

1. Capture / Obtain Network Traffic

Obtain a network traffic capture for analysis.

2. Identify Protocols

Examine the protocols present in the traffic.

3. Apply Filters

Use Wireshark filters to focus the investigation on relevant packets.

4. Analyze Packets

Examine packet details, source and destination information, ports, and protocol behavior.

5. Identify Findings

Document unusual, important, or security-relevant observations.

6. Report

Summarize the investigation and provide security recommendations.

---

🔐 Security Relevance

Network traffic analysis can help security analysts identify suspicious communications, unusual connections, malicious activity, and indicators that may require further investigation.
